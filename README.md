# 安大实验室安全 · 自动刷课助手

一个用于「安徽大学 - 实验室安全育人智慧学习系统」的 Tampermonkey（油猴）脚本：自动播放视频、自动作答配套题目、播完自动跳到下一节。

纯前端驱动，**不需要 token、不需要账号密码**，手动登录后即可全自动刷课。

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

## ✨ 功能特性

- ▶️ **自动播放**：静音播放，倍速可选（0.25x ~ 2x，与网页原生播放器一致）
- ✅ **自动答题**：题目弹出时自动选中正确答案并提交（答案取自页面已加载的数据，无需手动点击）
- ⏭️ **自动跳下一节**：本节播完后自动进入下一节
- 🖥️ **后台运行**：最小化窗口 / 切到别的标签页也能继续刷
- 🎛️ **悬浮面板**：倍速切换、暂停/继续、秒完成本节、跳到下一节

## 📦 安装

1. 在 Edge / Chrome 扩展商店安装 **Tampermonkey**（油猴）。
2. 打开 Tampermonkey → **新建脚本** → 删除默认内容 → 粘贴 [auto-study.user.js](auto-study.user.js) 全部内容 → `Ctrl+S` 保存。
3. 登录系统，进入任意一门视频课的详情页，脚本会自动开始（右下角出现悬浮面板即成功）。

> ⚠️ 需要能访问学校内网 `172.17.109.74` 才能正常使用。

## 🕹️ 使用

| 控件 | 作用 |
|---|---|
| 倍速下拉框 | 0.25x ~ 2x，与网页原生倍速一致（默认 2x） |
| ⏯ 暂停 / 继续 | 一键暂停 / 恢复视频、答题、自动跳节 |
| ⚡ 秒完成本节 | 立即作答本节全部题目并把视频快进到结尾 |
| ⏭ 跳到下一节 | 手动切到下一节 |

> 倍速也可直接用网页视频右键菜单里的「播放速度」改，脚本会自动跟随、互相同步。

## ⚙️ 配置

脚本顶部 `CONFIG` 对象：

| 参数 | 默认值 | 说明 |
|---|---|---|
| `defaultRate` | `2` | 默认倍速（可选 0.25 / 0.5 / 0.75 / 1 / 1.25 / 1.5 / 1.75 / 2） |
| `autoNext` | `true` | 视频播完后是否自动跳下一节 |
| `autoStart` | `true` | 进入课程详情页后是否自动开始 |
